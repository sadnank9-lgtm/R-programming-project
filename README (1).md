# R Programming Assignment

A collection of R scripts covering core programming and data-analysis concepts:
data frames, built-in datasets, lists, arrays, functions, loops, and descriptive statistics.

## Contents

| File | Topic | Key concepts |
|------|-------|--------------|
| [`Q1_employee_dataframe.R`](Q1_employee_dataframe.R) | Employee data frame | `data.frame`, `aggregate`, `tapply`, `order`, `cor` |
| [`Q2_mtcars_analysis.R`](Q2_mtcars_analysis.R) | `mtcars` dataset | `subset`, `quantile`, missing values (`na.omit`) |
| [`Q3_lists.R`](Q3_lists.R) | Lists | creating, modifying, nested lists |
| [`Q4_arrays.R`](Q4_arrays.R) | Arrays | 3-D arrays, indexing, `apply` |
| [`Q5_functions.R`](Q5_functions.R) | User-defined functions | prime check, BMI, summary stats, recursion |
| [`Q6_loops.R`](Q6_loops.R) | Loops | `for`, `while`, `repeat`, `next`, `break` |
| [`Q7_exam_scores.R`](Q7_exam_scores.R) | Exam scores | `sapply`, `ifelse`, manual mean/median/SD |

## Requirements

- R (version 4.0 or later recommended)
- No external packages required — everything uses base R.

## How to Run

From an R console:

```r
source("Q1_employee_dataframe.R")
```

Or from the terminal:

```bash
Rscript Q1_employee_dataframe.R
```
